## 산문 규칙 — 주석·커밋·문서 (사용자 명시 없이 항상 적용)

읽는 사람은 6개월 뒤의 동료다. 주석은 메모장이 아니다.

근거와 측정: [reports/agent-prose-readability.md](../../reports/agent-prose-readability.md), [reports/korean-prose-style.md](../../reports/korean-prose-style.md)

### 1. 근거 라우팅 — 쓰지 말라가 아니라 어디에 쓰라

헌법 §0은 "왜 이 비용을 지불했는가"를 항상 설명하라고 요구한다. 그 설명이 갈 곳을 여기서 정한다.

| 근거의 크기 | 목적지 |
|---|---|
| 코드가 말할 수 있다 | 이름·타입·테스트로 말한다. 주석 0줄 |
| 한두 줄로 끝난다 | 주석 1~3줄 |
| 그 이상 | `best-practice/` 또는 `reports/` 문서 + 주석에 링크 한 줄 |

판별 질문 하나. **"이 설명이 6개월 뒤에도 코드와 함께 갱신되는가?"** 아니면 문서로 뺀다.

### 2. 상한 (초과하면 위반)

| 대상 | 상한 |
|---|---|
| 타입 doc | 6줄 |
| 멤버 doc | 3줄 |
| 인라인 주석 | 2줄 |
| `[Tooltip]` | 80자, 태그 금지 (인스펙터는 리치 텍스트를 해석하지 않는다) |
| 주석 내 `<b>` `<i>` | 0개. 강조가 필요하면 문장을 줄인다 |
| 한 문장 | 100자 |

`<see cref>`는 실제로 따라갈 참조에만 쓴다. 산문 장식으로 쓰지 않는다.

### 3. 한국어 맞춤법 — 예외 없음

- **조사는 앞말에 붙여 쓴다** (한글 맞춤법 제41항). 앞말이 로마자·숫자·기호여도 같다.
  `UICardReaction을` `0.5가` `PlayMode는`처럼 쓴다. `UICardReaction 을`은 위반이다.
  식별자 경계를 드러내야 하면 백틱을 쓴다. `` `UICardReaction`을 ``
- **줄표 `—`는 문장 중간 삽입에 쓰지 않는다.** 쉼표, 괄호, 문장 분리로 대신한다.
  규정이 드는 줄표 용법은 제목 다음의 부제 표시 하나다.

### 4. 문체

- 주석·커밋·규칙·문서는 **한다체**로 통일한다. 한 문서 안에서 합니다체와 섞지 않는다.
- 사용자에게 보내는 대화 응답만 합니다체를 쓴다.

### 5. 은유 — 영어를 옮기지 않는다

판별 기준 하나. 한국어에서 먼저 쓰이던 비유인가, 영어 표현을 낱말로 옮긴 것인가.

| 쓰지 않는다 | 대신 쓴다 |
|---|---|
| 테스트가 문다 (bites) | 테스트가 검증한다, 보장한다 |
| 경고가 운다 (fires) | 경고가 뜬다 |
| 값이 화면에 산다 (lives in) | 값이 씬에 저장된다 |
| 설정 손잡이 (knob) | 설정 값, 옵션 |
| 그물 (safety net) | 안전장치, 검증 |
| 사람이 저작한다 (authored) | 사람이 직접 만든다 |

의인화된 무생물 주어도 같다. "매대가 말한다"가 아니라 "매대가 비면 더 살 것이 없다는 뜻이다"로 쓴다.

유지해도 되는 것도 있다. `자리`와 `길`은 한국어에 이미 있는 공간 비유이고, `굽기`는 Unity `bake`의 정착된 번역이며, `조용히 실패한다`는 업계에 정착한 표현이다.

### 6. 커밋

- 제목은 `<유형>: <바뀐 타입·파일 이름>을 <무엇> 한다` 형태로 쓴다. 50자 이하, **식별자 1개 필수**.
  식별자가 없으면 `git log --grep`과 `git bisect`가 그 커밋을 찾지 못한다.
- 본문은 6줄 이하 불릿 3~4개로 쓴다. "왜"만 적는다. 더 길면 문서로 빼고 링크한다.
- 은유 제목이 떠오르면 본문 첫 줄로 내린다. 색인을 만드는 것은 제목이다.

### 7. 금지

- 한 주석 안의 여러 문단, 자문자답("왜 X인가:"), 대안 비교 서술
- 은유로만 이루어진 설명. 도메인 은유는 한 번만 쓰고 그다음은 식별자로 부른다
- 과거 인시던트 서술을 주석에 재수록하기. 문서 링크로 대체한다

```bash
python tools/prose-audit.py --gate          # 길이·구조·검색성

```
