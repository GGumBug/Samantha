# Reflect

현재 세션의 인사이트를 저장소의 장기 지식으로 승격하는 승인 기반 워크플로우입니다.

## 실행

1. `reflection-curator` 커스텀 에이전트에게 현재 세션을 검토하도록 위임합니다.
2. 사용자가 focus keyword를 제공했다면 해당 주제만 검토합니다.
3. 에이전트는 파일을 수정하기 전에 아래 형식으로 후보를 제안해야 합니다.

```text
제안 N/전체
대상: 정확한 파일 경로
변경 요약: 2~4줄
재사용성: 0~3점과 근거
현재 줄수 → 예상 줄수
승인 선택: Y / N / L
```

4. 재사용성 0~1은 기본적으로 스킵을 권장합니다.
5. 사용자의 명시적 승인을 받은 제안만 별도 편집 단계에서 적용합니다.
6. 적용 후 관련 링크, README 인덱스, 200줄 제한, 테스트 또는 문서 검증을 확인합니다.

## 반영 위치

- 지속 작업 규칙: `AGENTS.md`
- 커스텀 에이전트 행동: `.codex/agents/*.toml`
- 반복 워크플로우: `.agents/skills/*/SKILL.md`
- 일반화된 패턴·안티패턴: `best-practice/*.md`
- 특정 작업의 분석·설계 기록: `reports/*.md`
- 훅 자동화: `.codex/hooks/`

## 금지

- 사용자 승인 전 파일 편집
- 현재 세션과 무관한 교훈 추가
- 기존 문서에 이미 있는 내용의 중복 승격
- 특정 프로젝트의 일회성 사실을 전역 원칙으로 일반화
- 여러 주제를 한 파일에 누적해 200줄 제한을 넘기는 변경
