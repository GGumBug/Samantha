# 경유 경로 단언 — 종단 상태가 같아도 거쳐 간 곳은 틀릴 수 있다

객체가 컨테이너 A → B → C 로 옮겨 가는 설계에는 **시작과 끝이 같으면서 중간만 틀린 결함**이 있다. 시작·끝 상태를 비교하는 테스트는 전부 통과하고, 어긋나는 것은 잠깐 스쳐 가는 경유 위치뿐이라 **사람이 눈으로 보고 신고하는 부류**가 된다. Double Down 턴 엔진 재구성(2026-08-29) 실측 — 뒤집은 카드가 규칙상 거쳐야 할 공용 바닥을 건너뛰고 더미에서 획득 더미로 직행했는데, 턴이 끝나면 양쪽 다 같은 곳에 있어 **어떤 테스트도 잡지 못했다**.

## 1. 왜 종단 동결이 못 잡는가

[golden-case-gate.md](golden-case-gate.md) 의 결론은 "중간값 말고 **종단값**을 동결하라"다. 그 결론은 **값 파이프라인**(채점 → 판정 → 정산처럼 단계마다 값을 변환하는 흐름)에서 옳다 — 어느 단계가 회귀해도 종단값이 달라지므로 케이스 하나가 전 축을 감시한다.

**소유권·위치 이동**은 성질이 다르다. 이동은 값을 바꾸지 않고 **소속만 옮긴다**. 경로가 달라도 종점이 같으면 종단 상태는 비트 단위로 동일하다 — 감시할 차이가 종단에 남지 않는다.

| | 값 파이프라인 | 소유권·위치 이동 |
|---|---|---|
| 단계가 하는 일 | 값을 변환 | 소속을 옮김 |
| 경로 오류가 종단에 남기는 흔적 | 남는다(값이 달라짐) | **없다**(종점이 같음) |
| 게이트 | **종단값 손계산 동결** | **경유 경로 단언** |
| 문서 | [golden-case-gate.md](golden-case-gate.md) | 본 문서 |

두 게이트는 경쟁하지 않는다. 한 기능이 양쪽 성질을 다 가지면 둘 다 필요하다.

## 2. 적용 트리거

- "A 를 거쳐 B 로 간다"가 **규칙으로 서술된** 이동 — 거치는 것 자체가 요구사항인 경우
- 경유지에서 다른 주체가 개입할 수 있는 이동(가로채기, 우선권, 동시 획득)
- 경유지가 **화면에 보이는** 이동 — 연출·애니메이션이 그 위치를 전제로 함
- 상습 도메인: 인벤토리 이관, 오브젝트 풀 회수, 드래그앤드롭, 카드·토큰 이동, 장바구니 → 주문, 스테이징 → 커밋

## 3. 처방 — 경로를 관측 가능한 값으로 만든다

경로는 **기록하지 않으면 존재하지 않는다**. 이동 API 가 결과 소속만 남기고 사라지면 단언할 대상 자체가 없다.

- **이동을 이벤트·스텝으로 노출** — 각 이동이 `(무엇, 출발, 도착)` 을 남기게 한다. 이미 스텝 기반 엔진이라면 추가 비용이 거의 없다
- **테스트는 시퀀스를 단언** — 종단 소속이 아니라 **거친 컨테이너의 순서**를 단언한다. `[더미, 바닥, 획득]` 과 `[더미, 획득]` 이 서로 다른 값이 되는 형태여야 한다
- **금지 케이스도 함께 동결** — "직행하지 않는다"는 부정 단언은 경로 시퀀스가 있어야 쓸 수 있다
- **런타임 자기 대조와 병행** — 실플레이에서만 재현되는 결함이면 [runtime-contrast-assertion.md](runtime-contrast-assertion.md) 의 장치를 이동 지점에 심어 불일치를 `LogError` 로 낸다

## 4. 설계 쪽 처방 — 우회할 수 있는 경유는 언젠가 우회된다

테스트보다 앞선 처방은 **직행 경로를 만들지 않는 것**이다. 이동 API 가 임의의 출발·도착을 받으면 직행은 합법 호출이고, 규칙은 호출자의 성실함에만 걸린다.

- 규칙상 필수 경유지가 있으면 **경유를 API 로 강제** — 임의 `Move(from, to)` 대신 `MoveToStage()` + `CommitFromStage()` 처럼 단계를 쪼갠다
- 직행 오버로드를 남겨야 한다면 부수효과 등가성을 별도로 검증한다([overload-semantic-equivalence.md](overload-semantic-equivalence.md))

## 종료 게이트

- [ ] 이동 규칙에 **필수 경유지**가 있는지 사양에서 확인했는가(있으면 본 문서 적용)
- [ ] 이동이 `(무엇, 출발, 도착)` 시퀀스로 관측 가능한가
- [ ] 테스트가 **종단 소속이 아니라 경로 시퀀스**를 단언하는가
- [ ] 직행이 API 상 합법이면, 강제 경유 형태로 바꿀 수 있는지 검토했는가
