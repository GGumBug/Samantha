# 제2 생산자 축 표류 — 타입에 축을 더할 때 생산 지점을 센다

한 타입을 만드는 곳이 둘 이상이면, 그 타입에 **축(필드)을 하나 더할 때마다 생산자 전부를 다시 채워야 한다**. 두 번째 생산자는 대개 생산자로 보이지 않는 이름 뒤에 있다 — 재생 모델, 프리뷰, 테스트 빌더처럼 **원본을 흉내 내는 쪽**이다. Double Down 획득패 4분류 배치(2026-08-04)에서 **같은 계급의 누락이 2회** 반복.

## 1. 제2 생산자는 "흉내 내는 쪽"에 숨는다

폴드(되감기) 모델은 스텝을 재생해 판을 재구성하고 `ToSnapshot()` 으로 `BoardSnapshot` 을 조립한다. 이름 어디에도 생산자라고 적혀 있지 않지만, 권위 상태와 **같은 타입을 만드는 두 번째 경로**다. 소비자로 오해하기 쉬운 것이 이 패턴의 본질이다 — 스냅샷을 **읽어서** 재생하는 것처럼 보이는데 실제로는 만든다.

상습 후보 — 코드에서 이 형태를 보면 생산자 명부에 넣는다:

| 후보 | 왜 생산자인가 |
|---|---|
| 재생·되감기·리플레이 모델 | 스텝을 되짚어 결과 타입을 **재조립** |
| 프리뷰·고스트·시뮬레이션 | 커밋 없이 같은 타입을 미리 만든다 |
| 테스트 빌더·픽스처 팩토리 | 최소 인자만 채우고 나머지는 기본값 |
| 역직렬화·마이그레이션 컨버터 | 옛 포맷 → 현재 타입 |

## 2. 실패 소음도가 발견 시점을 가른다 (실측 2회)

| 회차 | 더한 축 | 제2 생산자가 흘린 값 | 증상 | 발견 |
|---|---|---|---|---|
| 1 | `CardSnapshot.Kind` | `CardKind.None` | 배치가 **예외로 죽음** — 평범한 턴마다 | 즉시 |
| 2 | `SeatSnapshot.CapturedTally` | 빈 집계 | 배지가 **재생 내내 0** | 늦게 |

두 누락은 **같은 계급**이다 — 같은 타입군, 같은 제2 생산자, 같은 원인. 다른 것은 축의 성격뿐이다. 1회는 하위 코드가 그 값을 분기 키로 써서 즉시 터졌고, 2회는 표시용 수량이라 조용히 0 이 보였다.

여기서 얻는 규율: **1회를 겪고 "이제 폴드도 같이 고쳐야 한다는 걸 안다"고 생각하는 것으로는 2회를 못 막는다.** 시끄러운 실패는 기억을 만들지만, 다음 축이 조용한 축이면 그 기억이 발화하지 않는다. 조용한 축은 컴파일도 테스트도 "0 이 이상하다"고 말해 주지 않으므로, 사람의 기억이 아니라 절차에 걸어야 한다.

## 3. 선택 인자가 강제를 끈다

2회 누락이 조용했던 직접 원인은 생성자 신호다.

```csharp
// 선택 인자 — 기존 호출부를 안 건드려도 컴파일 통과, 기본값이 조용히 들어간다
public SeatSnapshot(..., CapturedTally tally = default)

// 필수 인자 — 컴파일러가 생산자 전부를 즉시 지목한다
public SeatSnapshot(..., CapturedTally tally)
```

선택 인자는 "기존 호출부를 안 건드리려는 편의"인데, 그 편의가 사들이는 것이 정확히 **누락의 침묵**이다. 필수 인자는 반대다 — 컴파일 에러 목록이 곧 **생산자 명부**이고, 그 명부는 공짜이며 빠뜨릴 수 없다.

**선택 인자를 허용하는 경우**: 저장소 밖 호출자가 있는 공개 API 의 하위 호환. 저장소 안에서 전부 고칠 수 있으면 **필수 인자가 기본값**이고, 선택 인자를 쓰기로 했다면 그 사유가 보고에 남아야 한다.

## 4. 제거는 사람이 세고, 추가는 컴파일러가 센다

[implicit-proxy-state-removal.md](implicit-proxy-state-removal.md) 와 방향이 정확히 대칭이다.

| | 방향 | 세는 대상 | 세는 주체 |
|---|---|---|---|
| 상태·접합부 **제거** | 읽기 지점 | 독자 전수 | **사람의 grep** — 자동화 불가 |
| 타입에 축 **추가** | 쓰기 지점 | 생산자 전수 | **컴파일러** — 필수 인자로 만들면 |

추가 쪽이 더 강한 처방이다. 규율을 성실함이 아니라 **도구에 맡길 수 있기** 때문이다 — 그러니 맡길 수 있는데 안 맡기는 선택(선택 인자)은 그 자체가 손실이다.

## 종료 게이트

- [ ] 축을 더할 타입명을 **이름만** grep — `new T(` · `ToSnapshot` · 빌더 · 팩토리 · 컨버터
- [ ] 결과를 생산자 표로 정리하고 **새 축 열을 행마다 채움** — 빈 칸 0건
- [ ] 새 축은 **필수 인자**로 추가. 선택 인자로 갔다면 사유를 보고에 명시
- [ ] 축이 조용한 값(수량·표시용)이면 재생·프리뷰 경로에서 **눈으로 1회 확인** — 시끄러운 축의 기억은 여기서 발화하지 않는다
