# Unity QA 체크리스트 & 테스트 표준

이 스킬은 Unity 게임 출시 전 QA 검증의 완전한 기준을 정의합니다.

---

## QA 심각도 분류

| 등급 | 기호 | 기준 | 릴리즈 가능 |
|-----|------|------|----------|
| Critical | 🔴 | 게임 크래시, 진행 불가, 데이터 손실 | ❌ 절대 불가 |
| High | 🟠 | 주요 기능 오작동, 심각한 시각 버그 | ❌ 수정 후 재검토 |
| Medium | 🟡 | 일부 기능 비정상, 경미한 시각 버그 | ⚠️ 판단 필요 |
| Low | 🟢 | 미미한 불편, 개선 권고 사항 | ✅ 다음 버전 |

**Go 기준**: 🔴 Critical 0개, 🟠 High 0개조건

---

## 섹션 1: 기능 테스트

### 플레이어 시스템
```
[ ] 기본 이동 — 좌우 이동이 모든 입력 방향에서 정상 작동
[ ] 점프 — 지상에서만 점프 가능, 공중 점프 없음 (설계 미포함 시)
[ ] 더블 점프 — 설계 포함 시: 공중에서 1회만 추가 점프
[ ] 대시 — 쿨다운 적용, 무적 판정 시간 정확
[ ] 공격 — 히트박스가 애니메이션 타이밍과 일치
[ ] 피격 — 무적 시간(iFrame) 정상 작동
[ ] 사망 — 사망 애니메이션 → 게임오버 화면 전환
[ ] 체력 회복 — 최대 체력 초과 회복 없음
[ ] 체력 감소 → UI 체력바 즉시 반영
```

### 적 시스템
```
[ ] 순찰 — 경로 범위 내에서만 이동
[ ] 플레이어 감지 — 감지 범위에서만 추격 시작
[ ] 추격 → 공격 전환 — 거리 임계값에서 정확히 전환
[ ] 사망 — 사망 후 드롭 아이템 스폰
[ ] 사망 애니메이션 → 일정 시간 후 오브젝트 풀로 반환
[ ] 벽/절벽에서의 경계 처리 (추격 중 떨어지지 않음)
```

### 게임 시스템
```
[ ] 씬 로드 — 로딩 완료 후 게임 정상 시작
[ ] 씬 전환 — 이전 씬 메모리 완전 해제 확인
[ ] 일시정지 — Time.timeScale = 0, 입력 차단
[ ] 재개 — Time.timeScale = 1, 정상 진행
[ ] 게임오버 → 재시작 — 모든 상태 초기화
[ ] 클리어 → 결과 화면 — 점수/기록 정확히 표시
[ ] 저장 — 데이터 정상 저장 확인
[ ] 불러오기 — 저장 데이터 정확히 복원
```

## 섹션 2: UI/UX 테스트

### 메뉴
```
[ ] 메인 메뉴 — 모든 버튼 클릭 반응
[ ] 설정 — 볼륨/해상도 변경 즉시 반영 및 저장
[ ] 일시정지 메뉴 — ESC/Back 버튼으로 토글
[ ] 대화창 — 텍스트 넘침(overflow) 없음
[ ] 모든 팝업 — 배경 클릭으로 닫기 (설계된 경우)
```

### HUD
```
[ ] 체력바 — 감소/증가 애니메이션 자연스러움
[ ] 스코어 — 실시간 갱신, 최대값 표시 이상 없음
[ ] 타이머 — 정확한 시간 측정 (Time.unscaledTime 사용 확인)
[ ] 쿨다운 인디케이터 — 실제 쿨다운과 동기화
[ ] 미니맵 — 플레이어 위치 정확
[ ] 아이템 슬롯 — 아이템 아이콘 정확 표시, 빈 슬롯 처리
```

### 해상도 & 반응형
```
[ ] 1920×1080 — 기준 해상도, 완벽한 레이아웃
[ ] 2560×1440 — UI 스케일 정상
[ ] 1280×720  — UI 잘림 없음
[ ] 16:10 비율 — 레터박스 없이 정상 표시
[ ] 모바일 (해당 시) — Safe Area 처리, 터치 타겟 크기 ≥ 44px
```

## 섹션 3: 성능 테스트

### FPS 기준
```
목표 플랫폼별 최소 FPS:
[ ] PC (중급) — 평균 60fps, 최소 45fps
[ ] PC (저급) — 평균 30fps, 최소 24fps
[ ] 모바일 (고급) — 평균 60fps, 최소 30fps
[ ] 모바일 (중급) — 평균 30fps, 최소 24fps

측정 방법: Unity Profiler → CPU 사용량, Frame Time(ms)
전투 씬(가장 복잡한 상황)에서 측정
```

### 렌더링
```
[ ] Draw Call — 씬별 목표치 이하 (TARS가 설정한 기준)
[ ] Batching — Static/Dynamic Batching 활성화 확인
[ ] 오버드로우(Overdraw) — Scene View > Overdraw 모드 확인
[ ] 그림자 — 필요한 오브젝트만 Cast/Receive Shadow 활성화
[ ] 텍스처 압축 — 플랫폼에 맞는 압축 포맷 적용
```

### 메모리
```
[ ] 최대 힙 메모리 — 허용 한도 내
[ ] GC 할당 — 런타임 프레임당 0KB 목표
[ ] 씬 전환 후 메모리 즉시 해제 확인
[ ] Addressables 언로드 — 미사용 에셋 즉시 해제
[ ] 텍스처 메모리 — 해상도에 맞는 Mip Map 적용 여부
```

### 물리
```
[ ] FixedUpdate 빈도 — Physics.fixedDeltaTime 설정 적절 (기본 0.02s)  
[ ] Collision Matrix — 불필요한 레이어 간 충돌 비활성화
[ ] Rigidbody Sleep — 정지 오브젝트 Sleep 모드 진입 확인
```

## 섹션 4: 엣지케이스 테스트

### 게임플레이 엣지케이스
```
[ ] 화면 경계 — 플레이어가 화면 밖으로 나가지 않음 (카메라 클램핑)
[ ] 동시 입력 — 좌+우 동시 입력 시 캐릭터 정지 또는 예외 없음
[ ] 빠른 연속 클릭 — 버튼 스팸 시 중복 실행 없음
[ ] 0 체력 — 정확히 0에서 사망, 음수 미발생
[ ] 최대 체력 초과 회복 — 최대값 클램핑 적용
[ ] 적 0마리 — 승리 조건 오작동 없음
[ ] 아이템 0개 — 빈 인벤토리 UI 정상 표시
```

### 씬/상태 엣지케이스
```
[ ] 씬 로드 중 입력 — 로딩 완료 전 입력 차단
[ ] 빠른 씬 재로드 — Singleton 중복 생성 없음 (DontDestroyOnLoad 확인)
[ ] 일시정지 중 이벤트 — Time.timeScale=0일 때 이벤트 발동 없음
[ ] 게임오버 직후 재시작 — 모든 정적 이벤트 구독 해제 확인
[ ] 저장 파일 없음 — 신규 플레이어 기본값으로 정상 시작
[ ] 저장 파일 손상 — 예외 처리 후 새 게임 시작
```

### 오디오 엣지케이스
```
[ ] 동시 효과음 15개+ — AudioSource 부족 없음 (AudioMixer 설정)
[ ] 씬 전환 — BGM 끊김 없이 페이드 전환
[ ] 볼륨 0 — 음소거 상태에서 오디오 연산 최소화
[ ] 느린 기기 — 오디오 레이턴시 허용 범위 내
```

## 섹션 5: 빌드 테스트

```
[ ] Debug 빌드 — 에디터와 동일한 동작 확인
[ ] Release 빌드 — 디버그 로그 없음, 성능 향상 확인
[ ] 빌드 크기 — 플랫폼별 허용 크기 이하
[ ] 첫 실행 — 퍼미션 요청, 초기 세팅 정상 동작
[ ] 재실행 — 이전 세션 데이터 정상 유지
[ ] 백그라운드 전환 — 일시정지 처리, 오디오 정지
[ ] 충돌 로그 — 크래시 없음 (Firebase/Unity Diagnostics)
```

## ⚠️ Gotchas — Claude가 자주 빠지는 QA/검증 함정 (반드시 숙지)

> 코드 작성 전/검증 시 주의하세요.

### G1. Time.timeScale=0 때의 로직 처리 누락
❌ 일시정지 상태에서 UI 애니메이션이나 로직이 멈추는 함정
✅ UI 중 애니메이션이 필요한 부분은 `unscaledDeltaTime` 또는 DOTween의 `.SetUpdate(true)`를 사용해야 합니다.

### G2. DontDestroyOnLoad 중복 생성 문제
❌ 씬 리로드 시 Singleton 객체가 계속 늘어나는 함정
✅ `Awake`에서 자신과 같은 타입의 Instance가 이미 존재하는지 체크 후 `Destroy(gameObject)` 처리 필수.

### G3. 메모리 누수를 고려하지 않는 잦은 인스턴스화
❌ 게임 진행 중 무기, 투사체, 적군 등을 `Instantiate`/`Destroy` 반복
✅ 주기적으로 생성되는 객체는 반드시 **오브젝트 풀링(Object Pooling)** 전략을 사용하는지 확인(Sonny에게 요청)해야 합니다.
